# datasource-meshgpt-dataset-02

A notebook that trains a text-conditioned mesh autoencoder and transformer on a small labelled mesh set, then generates meshes from text.

## Build and run

Run `MeshGPT_demo.ipynb` cell by cell in a notebook runtime with a GPU. It installs its own Python dependencies and keeps its dataset and checkpoints in a mounted drive folder.
